# Third-party notices

## Meridian Shaded chess pieces

The twelve SVG files under `src/assets/pieces/meridian_shaded/` come from the **Meridian Shaded** set in Karl Maron's Chess SVG Piece Sets collection.

- Source: https://github.com/kmar/chess_svg_piece_sets/tree/main/meridian_shaded
- Project description: a shaded SVG interpretation of a chess-piece design published in a German newspaper in 1952
- License: public-domain dedication, reproduced in `src/assets/pieces/meridian_shaded/LICENSE`

The artwork is bundled with the application, so chess pieces do not require a runtime network request. The source geometry is unchanged; the interface applies only restrained CSS sizing and shadow treatment to fit the board.
